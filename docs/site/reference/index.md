# Reference

## Public API

| item | what it is |
|---|---|
| `EvalEngine` impl | the `engine-exec` contract |
| bytecode compilation | scheme lookup happens at compile time, not per node |
| conformance suite | shared cases asserting parity with the tree-walk engine |

## Crate

| crate | role |
|---|---|
| `hnl-engine-exec-bytecode` | engine implementation |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
